Pre-release — public contracts are defined; behavior lands per block.

01

Three ports, one core.

The host owns every edge. kitcut never imports a codec, an ML runtime, or a server client — it defines the seams and ships the identity element of each.

02

Five packages.

Fine-grained. Compose what you need. Each ships its public types first so you integrate against a stable seam while internals fill in.

  • @kitcut/processor

    Plugin port

    The per-frame effect contract. Gaze correction, background, watermark — concrete processors live outside core.

    VideoProcessor · passthrough · composeProcessors

  • @kitcut/export

    Adapter port

    How a timeline becomes a file: in-browser renderer, server service, ffmpeg.wasm worker — your call.

    ExportAdapter · createClientRenderer

  • @kitcut/timeline-core

    State + persistence

    The clip/timeline model. Persistence is a port — core never imports a backend.

    TimelineState · PersistenceAdapter

  • @kitcut/recorder

    Capture + Input port

    Headless camera & screen capture today; paired-phone transport is a registerable provider.

    CaptureProvider · camera · screen

  • @kitcut/editor-react

    Headless · BYO UI

    Radix-style primitives + hooks. No styling, no design system. Injectable translator, English default.

    EditorConfig · Translate

  • @kitcut/demo

    Reference app · not published

    The styled implementation, so the headless packages stay demoable. You're looking at it.

    private · static
